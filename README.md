# Моє Світло — Telegram Mini App магазин

Стек: Node.js + Express + MongoDB (mongoose). Товари, описи та **фото зберігаються в MongoDB**.

## Запуск
1. `npm install`
2. `cp .env.example .env` і заповніть значення
3. `npm start`
4. Магазин: `http://localhost:3000` · Адмінка: `http://localhost:3000/admin.html`

## Підключення до Telegram
1. Розгорніть на сервері з HTTPS (Render, Railway, VPS + nginx) або для тесту: `ngrok http 3000`.
2. Вкажіть цю адресу в `WEBAPP_URL`.
3. У @BotFather: `/newapp` (або `/setmenubutton`) → вкажіть URL → завантажте `public/logo.png` як іконку.
4. Бот відповідає на `/start` кнопкою «Відкрити магазин».

## Адмінка (/admin.html)
- Додавання, редагування, видалення товарів; завантаження фото (стискається до 900 px і зберігається в MongoDB).
- Перемикач «В наявності» ховає товар із каталогу.
- Перегляд замовлень і зміна статусу. Нові замовлення також приходять у Telegram на ADMIN_CHAT_ID.

## Безпека
- Замовлення приймаються лише з валідним підписом Telegram `initData`; ціни беруться з бази, а не з клієнта.
- Адмін-API захищено паролем із `.env` — обовʼязково змініть його і використовуйте HTTPS.

## Деплой на Render
1. Залийте проєкт на GitHub (`.env` не комітиться — він у `.gitignore`).
2. Render → **New → Blueprint** → виберіть репозиторій (підхопиться `render.yaml`) або **New → Web Service** (Build: `npm install`, Start: `npm start`, Health Check: `/healthz`).
3. Заповніть змінні: `BOT_TOKEN`, `MONGO_URI`, `ADMIN_PASSWORD`, `ADMIN_CHAT_ID`, `SUPPORT_USERNAME`.
4. Після першого деплою скопіюйте адресу `https://moe-svitlo.onrender.com` у `WEBAPP_URL` і підключіть її в @BotFather.
5. MongoDB Atlas → Network Access → додайте `0.0.0.0/0` (Render має динамічні IP).

## Щоб сервіс не засинав
- Вбудований самопінг: сервер кожні 10 хв звертається до свого `/healthz` (адреса береться з `RENDER_EXTERNAL_URL`).
- Для надійності додайте зовнішній монітор (UptimeRobot / cron-job.org): HTTP-запит на `https://<ваша-адреса>/healthz` кожні 5 хв.
- Безкоштовний план Render дає 750 год/міс — одного сервісу, що працює постійно, вистачає.

## Нова пошта та оплата
- **Доставка**: покупець обирає місто та відділення/поштомат зі списку Нової пошти (пошук через API; ключ `NOVA_POSHTA_API_KEY` зберігається лише на сервері).
- **Накладений платіж**: оплата на пошті при отриманні (комісію НП за переказ коштів сплачує отримувач).
- **Повна оплата**: якщо задано `MONO_TOKEN` — створюється рахунок Monobank Acquiring, статус «Оплачено» проставляється автоматично (сервер сам перевіряє статус рахунку). Без токена показується номер картки `PAYMENT_CARD`, а статус оплати змінюється вручну в адмінці.
- ТТН у Новій пошті створюйте в кабінеті НП: адреса отримувача й телефон є в замовленні.
